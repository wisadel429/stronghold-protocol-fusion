# 第三期「卫戍协议：规程」适配计划（提前准备）

日期：2026-11-08
依据：官方 2026-11-08 热更资源解包报告 + 391 条 UI 原文（`docs/reference/`）。

## 1. 已确认的事实

- 本期内部代号 `act3autochess`，本地资源版本 `26-11-06-12-42-25-70182449`，更新完成于 16:11。
- 地图 10 张（m01–m06、m09–m12），子关 30 个；新增 2 首首领曲 + 1 首系统曲；新增 Closure / Iron 变体皮肤与活动家具。
- 大厅新增三种入口（普通 / 困难 / 急速）、精确匹配、组队方式（创建队伍 / 加入队伍 / 房码邀请）。
- 新机制线索：**自编干员**（选 2 名加入编队）、**特训敌人**、**共同敌手**（漏怪扣双方生命）、**决战回合**、**三星评价**、称号判定、按阶级/羁绊筛选、道具图鉴、主题语音。
- 数值表（干员、盟约、敌人、关卡）仍在 `anon\*.bin` 的 LZHAM 块里，本机工具链无法解出；**精确数值暂不可得**。

## 2. 与现有代码的对应关系

| 官方机制 | 现有模块 | 改动量 |
| --- | --- | --- |
| 普通 / 困难 / 急速模式 | 大厅模式卡 + `DIFFICULTIES` | 小：新增入口与难度映射 |
| 精确匹配 / 组队方式 / 房码邀请 | 已实现的匹配 + 缺人同盟 + 房间码 | 中：补「创建队伍/入队伍」界面与文案 |
| 三星评价 | `screens/settle.js`、`server/match/settle` | 中：评分规则未知，需官方规则或自定 |

| 特训敌人 | 敌人表、波次（`data/enemies.json`、`waves.json`） | 大：需敌人数据 |

| 道具图鉴 / 称号 / 主题语音 | `ui/` 收藏类界面 | 中：数据与入口 |

## 3. 建议的推进顺序

1. **P1 文案与入口（可立即做，不依赖数值）**
   - 大厅三入口（普通/困难/急速）与「精确匹配」文案；
   - 「选择组队方式 / 创建队伍 / 入队伍 / 复制房间码邀请」界面；
   - 官方 391 条字符串里可用的条目加入 i18n（中/英/日/韩/繁中）。
2. **P2 结算（规则可先自定后替换）**
   - 三星评价的评分展示与称号占位，等官方规则确定后只换算法。
3. **P3 自编干员**
   - 开局前「选择 2 名干员加入编队」步骤；候选池可先用现有干员数据，官方池子等表。
4. **P4 引擎机制**
   - 共同敌手 → 决战回合 → 特训敌人（依赖官方敌人/关卡数据）。
5. **P5 数值落地**
   - 先解决 LZHAM 解码（`lzham_codec` 编译或带 LZHAM 的解包器），再导入 gamedata 表格，统一替换占位数值。

## 4. 需要你决定/提供

- 优先级：先做 P1+P2（可见、低风险），还是直接攻 P3/P4？
- 本期是否要严格对齐官方数值？若要，需要先解决 LZHAM 解码或提供官方表格导出。
- 大厅入口是否按官方改成「普通/困难/急速」三档，还是保留现有「独立/同盟/拓展」结构？
